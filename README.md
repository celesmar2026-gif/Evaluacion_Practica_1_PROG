# Evaluación Práctica 1 - Programación III M1

Este repositorio contiene la resolución de la Evaluación Práctica 1, enfocada en el manejo de rutas con Node.js y el uso de tipos de datos avanzados con TypeScript.

## 📂 Estructura del Proyecto

* **/Ejercicio_1**: Servidor dinámico en Node.js para la intercepción de parámetros (Animal Favorito).
* **/Ejercicio_2**: Implementación de Enumeraciones (Enums) en TypeScript para categorías de películas y países.

## 🛠️ Tecnologías Utilizadas
* **Motor de ejecución:** Node.js v12.22.9
* **Lenguaje:** TypeScript v4.5 (versión seleccionada por compatibilidad de entorno)
* **Sistema Operativo:** Linux Mint (Hardware Canaima)

## 🚀 Instrucciones de Ejecución

1. **Ejercicio 1:** Entrar a la carpeta y ejecutar `node server.js`. Acceder a `http://localhost:3000`.
